分者隐私政策

本政策覆盖分者 App 的个人信息处理，包括个人记录、游戏进度、备份、购买及相关权限。

适用范围与负责主体

本政策说明分者如何处理个人记录、游戏进度、备份、购买及权限相关信息。本 App 的发布与负责主体为大熊猫侯佩|PandaHopy。支持与隐私联系：19796174@qq.com。Apple及你主动使用的邮件、文件存储或分享服务，按各自政策处理由其提供的服务。

本机记录与用途

App可在本机保存你填写的任务、目标、描述、日记、评估、计时计数、签名和自定义名称，以及对应日期、时区、游戏进度和资产。这些信息用于展示记录、计算游戏规则、回顾和恢复。语言、外观、通知设置等作为本机偏好保存。请只填写所需内容，不要输入身份证号、支付密码或不必要的他人隐私。

备份、iCloud与导出

你可通过对应功能备份或导出完整游戏记录，其中可能包含任务、日记、签名和交易/资产记录。启用或进入iCloud备份功能时，App通过Apple iCloud服务查找、下载或保存备份；这可能发生网络传输。导出的新备份使用加密封装及完整性校验，减少随意阅读并发现篡改；它无需用户密码，其他兼容App安装也能恢复，因此不是仅你持有密钥的端到端加密。旧备份可能仍是明文，请自行妥善保管或删除。

购买、订阅与安全凭据

Apple处理付款及其账户信息，App不需要你提供支付卡号或Apple账户密码。App通过Apple签名交易验证购买，在本机保存商品/交易标识、时间、环境、交付、订阅覆盖期及钱包事件等必要事实。旧权益承接和防止重复领取可能保存Apple应用交易标识的哈希及最小Keychain记录；这些仍可能关联同一购买，不等于完全匿名。当前版本不使用App自建服务器验证内购，不代表Apple服务无需联网。

权限与本地提醒

通知默认关闭，由你主动开启；App按设置为到期任务、野游、修炼和每日未评估安排本地提醒，正文不包含任务、英雄或宠物名称。iOS权限、专注模式及系统策略决定是否和何时呈现。保存庭院明信片等功能按需申请照片写入权限；头像相关拍摄或选择由对应系统流程处理。你可以拒绝可选权限并继续使用无关功能，也可在系统设置中更改授权。

主动分享与联系

导出、分享、保存图片或给支持邮箱发信，可能把你选择的内容交给Apple或你选择的其他服务。请在分享前检查是否含私人记录。处理支持请求时，我们会使用你主动提供的邮件地址、问题描述和必要诊断来回复和排查；无需提供密码、验证码或完整私密备份。若排查确需更多资料，将说明范围和用途，不把联系行为当作营销或未来AI授权。

AI与其他处理

当前发行版关闭AI功能，不为使用App要求你向AI服务提交记录。源码保留的AI能力不构成当前上传授权；以后启用前将说明服务方、数据和用途，并按需要取得单独授权。本次条款确认不授权跨App追踪、广告画像或新增第三方数据分享。

保留、删除与换机

本机记录在你继续使用和保留它们时用于App功能；你可以使用实际提供的删除/重建操作或系统方式管理本机数据。不可逆清除会另行告知。删除App通常会移除其本机沙盒数据，但不自动删除iCloud或已导出的文件、Apple购买记录，也不保证移除必要Keychain凭据；订阅也不会自动取消。你需要在相应文件服务中另行管理备份。支持邮件及随附资料仅在处理你的请求、处理相关争议或履行法定义务所需的最短期间内保留。保留必要性消失后，我们将删除或去标识化处理；你也可通过联系邮箱提出删除请求。如仍须依法保留，我们会说明原因。

你的选择与请求

你可以更改语言、关闭可选权限、管理自己的记录和备份、在Apple账户中管理订阅，并通过联系邮箱提出访问、更正、删除或其他适用的数据权利请求。我们会按适用法律及实际控制范围处理，并说明必要身份核对或合法保留的理由，不要求你无关地提交证件。撤回必要条款确认后App可停留说明页；不会因此自动删除记录或取消订阅。若仍需访问已有数据，可联系支持，不应为获取帮助被迫重新购买。

安全措施与局限

App采用平台存储保护、签名交易核对和备份完整性校验等措施，减少非预期访问和重复交付风险；没有系统能保证绝对安全。拿到导出文件、已解锁设备或技术工具的人仍可能获得内容。请妥善保护设备、系统账户和备份，不向他人透露验证码或购买凭据。我们不会用“已加密”来保证数据永不泄露。

政策网站托管

本政策网站由 GitHub Pages 托管。访问网页时，GitHub 会为安全目的记录并保存访问者 IP 地址等技术访问信息，具体处理见 GitHub 隐私声明。浏览政策网页与 App 本机记录的存储是不同的处理场景，不会仅因你打开网页而将 App 中的任务、日记或备份上传至该网站。

更新与联系

本政策变化时会提供对应版本和生效日期；涉及实质变化或新数据用途时按要求告知并取得必要授权，普通换语言不改变已签原件。本版本公开网址为 https://hopy11.github.io/iScorer/privacy.zh-Hans.html。任何问题可发至 19796174@qq.com。
